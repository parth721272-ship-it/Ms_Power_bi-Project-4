# Power BI HR Analytics Dashboard

## Project Overview
This project is an interactive Human Resources (HR) Analytics Dashboard created using Microsoft Power BI. It focuses on workforce overview, employee attrition analysis, and compensation analysis to help understand employee-related data and support data-driven HR decisions.

## Project Objectives
- Analyze overall workforce information.
- Understand employee attrition patterns.
- Explore employee compensation.
- Present HR metrics through interactive dashboards.
- Improve data visualization and reporting skills.

## Dashboard Pages

### 1. Workforce Overview
Provides a summary of workforce information using visualizations and key performance indicators (KPIs).

### 2. Attrition Analysis
Focuses on employee attrition patterns to help identify trends and areas that may require further investigation.

### 3. Compensation Analysis
Presents compensation-related information to support the analysis of employee pay and workforce compensation patterns.

## Skills Demonstrated

## Business Value
This dashboard demonstrates how HR data can be organized into meaningful visual reports. It can help HR teams explore workforce composition, review attrition trends, and understand compensation patterns.

The findings should be interpreted in the context of the underlying dataset and should not be treated as proof of the causes of employee attrition.
